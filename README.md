**AP Computer Science Principles**


A collection of Python projects and exercises from my AP Computer Science Principles course during my senior year of high school.
This repository contains some of my earliest programming work and is preserved largely in its original form to show my progression while learning Python and foundational programming concepts.

**Projects**

Projects include a command-line calculator, ASCII art generator, Advent of Code exercises, interactive programs, and AP CSP performance tasks.

**Note**

These programs were created as coursework while I was learning to program. They reflect my knowledge and coding style at the time and have intentionally not been modernized.
